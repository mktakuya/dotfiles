# 外部サービスのコンテンツを更新する

Notion・Jira などの外部サービスは、エージェントの知らないところでユーザー自身が編集している。
そのため「会話中に取得した内容」を前提に書き込むと、ユーザーの手動変更を黙って消してしまう。

## 手順

### 1. 更新直前に再取得する

**会話中にすでに取得済みであっても、書き込む直前に必ず読み直す。**

- Notion: `mcp__notion__notion-fetch` でページを取得する
- Jira: `/read-jira-workitem` の手順で `acli` から取得する

### 2. 再取得した内容と差分を確認する

会話中に把握していた内容と再取得した内容が違う場合は、勝手にマージせずユーザーに確認する。

### 3. 書き込む

- Notion: `mcp__notion__notion-update-page`
- Jira の description: `/update-jira-workitem` スキルの手順に従う（ADF 形式のため専用手順が必要）

## 注意事項

- 「更新前に再取得」は例外なく適用する。取得から書き込みまでの間に別のツール呼び出しを挟んだ場合も、もう一度取得し直す
- 破壊的な更新（既存の節を丸ごと差し替える等）では、更新前の内容をローカルに保存してから書き込む
