# Codex 用グローバル指示

このファイルは Codex 専用のグローバル指示であり、`~/.codex/AGENTS.md` として読み込まれる。
Codex Desktop のパーソナライズ設定を変更すると、その内容もこのファイルに書き込まれる。

プロジェクト横断の共通ガイドラインは `~/AGENTS.md` にあり、Claude Code など他のエージェントとも
共有している。Codex 固有の設定だけをこのファイルに書き、共通のルールは `~/AGENTS.md` に書くこと。

## 共通ガイドライン

`~/AGENTS.md` は Codex では自動的に読み込まれないため、セッションの最初に必ず読み、その内容に従う。
